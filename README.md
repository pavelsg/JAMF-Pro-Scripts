# JAMF-Pro-Scripts

Scripts that I have developed over the years working with JAMF Pro.  

## Packaging utilities

[`Packaging/build-file-package.zsh`](./Packaging/README.md) builds validated macOS Installer packages from explicit file or nested-directory mappings. It can be reused for branding assets, configuration data, templates, and other static files distributed through Jamf Pro.
